Cloudy ships with a large curated collection of games and apps, all accessible directly from the interface without any additional setup. Whether you want to kill time with a quick browser game, access a productivity tool, or stream full PC games through the cloud, everything is a single click away.

## Games Library

The games library is available at `/a`. It contains a wide variety of titles spanning IO games, classics, browser games, retro console emulators, multiplayer games, Flash games, and more.

You can filter games by category using the dropdown on the games page, or use the search bar to find a title by name.

**Example games in the library:**

- Slope
- Krunker
- 1v1.LOL
- Cookie Clicker
- Minecraft Classic / Eaglercraft (1.5.2, 1.8)
- Among Us (Scratch)
- Run 3
- Bloons TD Battles & Bloons TD Battles 2
- Retro Bowl
- GBA, Nintendo DS, Nintendo 64, and PlayStation 2 emulators
- Gartic Phone, skribbl.io, and other multiplayer games
- Age of War, The Impossible Quiz, Helix Jump, Snow Rider 3D, and hundreds more

**Game categories available:**

| Category | Description |
|---|---|
| All | Every game in the library |
| Android | Android games via cloud streaming |
| Multiplayer | Two-player and online games |
| Sports | Sports-themed titles |
| Flash | Preserved Flash games |
| Emulator | Retro console emulators |
| Local | Games that run fully offline |

## Apps Library

The apps library is available at `/b`. It includes social platforms, streaming services, productivity tools, AI tools, messaging apps, and more.

You can filter apps by category or search by name.

**Example apps in the library:**

- YouTube & YouTube Alternative (Invidious)
- Spotify
- Discord (including Canary and PTB)
- Google, Google Gemini, Google Mail (Gmail)
- ChatGPT
- GitHub
- Twitch
- Now.GG and Now.GG (NowGG.me) [Working]
- Geforce NOW

**App categories available:** Social, Streaming, Messaging, TV & Movies, Game Sites, Cloud Gaming, Tools, AI, Emulator, Mail, and more.

## Cloud Gaming

Cloudy's apps library includes direct access to two major cloud gaming platforms, so you can play demanding games entirely in your browser.

<CardGroup cols={2}>
  <Card title="Now.GG" icon="mobile">
    Play Android games in your browser via the Now.GG cloud. No APK downloads or emulators required — just click and play. Both the standard Now.GG and the NowGG.me mirror are listed in the apps library.
  </Card>
  <Card title="Geforce NOW" icon="display">
    Stream full PC games through NVIDIA's Geforce NOW service. If you already have a Geforce NOW account and supported game library, you can launch sessions directly from Cloudy's apps page.
  </Card>
</CardGroup>

## Requesting Games or Apps

Don't see a game or app you want? You can request it through the official repository.

<Note>
  Open a GitHub issue using the **Game Request** template to suggest a new addition to the library. The Cloudy team reviews requests and adds new content regularly. You can also click the **"Request A Game"** card directly from the games page (`/a`) to be taken to the request form.
</Note>

<Tip>
  For the smoothest experience, open games from inside the **Tab System** (`/d`). Games load in an isolated tab with fullscreen support and navigation controls, keeping the rest of Cloudy accessible at the same time.
</Tip>
